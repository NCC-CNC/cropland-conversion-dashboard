# Web app

Vite, TypeScript and MapLibre GL JS static site. A user draws a polygon; the
browser sums pre-computed 1 km grid cells whose centroid lies inside it and
shows hectares, percent and annual rate of natural habitat converted to crop,
by class, for each interval. No backend.

## Commands

Node 20.19 or newer.

```bash
npm ci
npm run dev        # dev server
npm run typecheck
npm test           # Vitest
npm run build      # typecheck, then production build into dist/
npm run preview    # serve dist/
npm run fixture    # regenerate the synthetic demo data
```

`VITE_BASE` sets the deploy base path (default `/cropland-conversion-dashboard/`).
Use `VITE_BASE=/ npm run build` to serve from a domain root.

## Data

The app reads `public/data/areas.json` and, for each area,
`public/data/<area_id>/meta.json` and `cells.json`, as specified in
[`docs/design/02_mvp_data_contract.md`](../docs/design/02_mvp_data_contract.md).
Any number of areas is supported; an area picker appears when there is more
than one.

`public/data/demo-fixture/` is SYNTHETIC data generated by
`scripts/gen-fixture.mjs`, only so the interface can be developed. The app
hides it as soon as at least one other area is listed (id or name containing
"fixture"). Do not use its numbers for anything.

## Code layout

- `src/lib/summary.ts`: point in polygon over cell centroids (bbox prefilter,
  then Turf), per-class sums, percent and annual rate, selection status.
- `src/lib/csv.ts`: CSV export of the current summary.
- `src/lib/areas.ts`, `grid.ts`, `data.ts`, `format.ts`, `types.ts`.
- `src/render.ts`: builds the summary panel, chart and About section with
  `textContent` (no HTML injection from data files).
- `src/main.ts`: map, drawing and wiring.
- `src/lib/lib.test.ts`: unit tests, including a hand computed four cell case.

## Notes

- Drawing uses terra-draw with its MapLibre adapter (polygon, rectangle, and
  select/edit modes). Because drawing needs a pointer, "Use map view" offers a
  keyboard-friendly way to select the current view as a rectangle.
- The basemap is OpenStreetMap raster tiles (no key). It is fine for a
  low-traffic demo; switch to a hosted or self-served style if usage grows, as
  the OSM tile policy requires.
- MapLibre GL JS v6 loads its worker from a separate file. `npm run dev` and
  `npm run build` copy it to `public/maplibre/` (git-ignored) and the app
  points `setWorkerUrl` there.
- The grid overlay is thinned beyond 20,000 cells; summaries always use every
  cell.
- Selections with fewer than 5 cells show an uncertainty warning.
