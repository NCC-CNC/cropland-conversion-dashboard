# Session Handoff: 2026-11-20

## Summary

Went from an empty repo to a live MVP: a static web map on GitHub Pages at
https://ncc-cnc.github.io/cropland-conversion-dashboard/ that summarizes
natural habitat converted to crop inside a user-drawn shape, from real AAFC
Annual Crop Inventory data for one test window (Alberta Parkland near
Stettler, 40 x 40 km). The next session's job is to improve the app as much as
possible in one session.

## Completed

- Design note for the spike (`docs/design/01_feasibility_spike.md`), ADR 0002
  (Vite, TypeScript, MapLibre, GitHub Pages) and the pipeline to web data
  contract (`docs/design/02_mvp_data_contract.md`). Closes #4.
- `pipeline/`: Python pipeline that pulls clipped ACI exports from the AAFC
  ImageServer, harmonizes classes, applies a noise filter and writes a 1 km
  grid. 42 pytest tests, run in CI.
- `web/`: Vite + TypeScript + MapLibre + terra-draw app with polygon and
  rectangle drawing, per-interval tables, bar chart, CSV export, "About this
  data" caveats. 15 Vitest tests, run in CI.
- Pages deploy (`pages.yml`) enabled and working; solo-maintainer auto-merge
  workflows activated (matches the login `ricschuster`, since the repo is
  org-owned). Issue #5 closed. PRs #7 to #13.
- Rectangle drawing fix (#13): the first version needed click, move, click and
  a drag did nothing. It now works by press and drag with a preview. This was
  missed because only "Use map view" was tested on the live site at first.

## Current state

- Data: `web/public/data/ab-parkland-stettler/` (1,527 cells, 0.2 MB) plus a
  synthetic `demo-fixture/` the app hides once a real area exists.
- Headline numbers for the window, 2011 to 2025: about 3,460 ha converted
  (9.8% of natural cover); from 2016: about 3,890 ha (8.0%); from 2021: about
  1,600 ha (3.9%). Filter: crop also in 2024, patches under 0.5 ha removed,
  tame pasture and forage (code 122) not counted as crop, cells already crop in
  an earlier snapshot excluded from the baseline.
- Known limits:
  - ACI class labels drift a lot between years (grassland is 17%, 13%, 3.7%,
    5.6% of the window in 2016, 2021, 2024, 2025; shrubland nearly vanishes in
    2025). The split by natural class is unreliable; totals are better. Small
    selections can show odd class values (for example 0 ha grassland in 2011
    but 38% converted from 2016).
  - The 2011 baseline has less natural cover and no earlier year to filter
    against, so it understates conversion.
  - Counting pasture and forage as crop roughly doubles 2011 and 2021 results.
  - No independent validation yet (#6).
  - The ImageServer is Web Mercator, so the 30 m request is resampled once.
  - One area only; OSM public tile servers for the basemap.
- Test harness: Playwright scripts used for checks lived in the session
  scratchpad (gone later). Recreate with a headless Chromium, launch args
  `--no-sandbox --use-gl=swiftshader --enable-unsafe-swiftshader`, and drive
  real mouse gestures (down, move, up) rather than only buttons.
- Housekeeping: `.claude/worktrees/` holds two leftover agent worktrees
  (`agent-a45ce024dc2887a3f`, `agent-ad941cb47f5ac14ac`); remove with
  `git worktree remove` once nothing is needed from them.

## Next actions

Suggested order for an "improve the app" session; test every control on the
live site with real gestures before calling anything done.

1. Make class results trustworthy: collapse to a robust "natural" total as the
   headline, and either merge unstable classes (grassland with shrubland) or
   flag per-class values as indicative. Revisit the class mapping per year.
2. Validate (#6): compare the Stettler numbers with FACETS 2024 (Fyson et al.),
   StatCan ecosystem accounts and the AAFC 2026 report; log definition
   differences in a design note. Tune filter defaults from that (#3).
3. Reduce the noise at the 2011 baseline (for example use 2012 or a 2010 to
   2012 composite if coverage allows) and decide snapshot years (#2).
4. More coverage: add areas through the pipeline (a second Prairie window and
   a Mixedwood Plains window), or a larger extent with tiling; keep
   `cells.json` small.
5. Map UX: show the converted cells as a heat layer, label the selection with
   its area, uncertainty message for small selections, keyboard drawing,
   a share link that encodes the shape, better mobile layout, a basemap that
   does not depend on the public OSM servers.
6. Output polish: units and rate wording, an accuracy note per interval, CSV
   with caveats, a short methods page linked from the app.
7. Repo: set the `AUTO_MERGE_TOKEN` secret so merges close linked issues, add
   an end to end browser test to CI, and update CHANGELOG.md.

## Risks or decisions needed

- Whether tame pasture and forage should count as conversion. The brief says
  crop; it changes results by about 2x. Needs an owner decision.
- Honest framing: until validated, the numbers are a prototype and the UI says
  so. Do not use them in a grant without the caveats.
- `AUTO_MERGE_TOKEN` needs a fine-grained PAT from the maintainer; the org may
  restrict PATs.
